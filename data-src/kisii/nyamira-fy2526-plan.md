# Nyamira FY2025/26 in the money data: plan

## Finding: the gap is already closed on the site
- `src/lib/county-money.js` sets `LAST_FY = '2025/26'` and builds every year with `fiscalYears()` from the national registry (Controller of Budget extracts). So the Money pages already show FY2025/26 (`src/lib/county-money.test.js` asserts 13 years and that the last one is FY2025/26).
- `src/data/money.json` is the legacy file (12 years, to FY2024/25). Its consumers include the national app's data build, so it cannot take a new year without the chain below.

## (1) Files that must change together to add a year to money.json
1. `src/data/money.json`: the new year record (fields as in FY2024/25).
2. `national-budget/data.json`: regenerated by `node national-budget/build-data.mjs` (reads `src/data/*.json`, via `ND_DATA` or the default path). Enforced by `national-budget/build-data.test.mjs` "data.json is reproducible from build-data.mjs and src/data".
3. `national-budget/kenya-budget.html`: embeds `data.json` in `<script id="data">`. Enforced by "kenya-budget.html embeds the current data.json" (same file).
4. `scripts/county/check-county.mjs` ("the county registry passes every check") and `county-money.js` "every year money.json had is the same here, except the equitable share, which is now split" (`src/lib/county-money.test.js`): the year must agree with the registry, and the equitable share is now split into its own field, so the new record needs `eqShare` and `pending` set consistently with the registry or left null with a note.
Run order: edit money.json, run `node national-budget/build-data.mjs`, regenerate the HTML embed, then `npm test`. The chain is the national product's; if it should not change, keep FY2025/26 out of money.json (the current state).

## (2) Does the national app regenerate from src/data?
Yes, in part: `national-budget/build-data.mjs` reads `src/data/*.json` and writes `national-budget/data.json`; `kenya-budget.html` embeds that file. `apps/national` reads its own data files and `data/national/sources.json` (which already records the FY2025/26 report). It is not regenerated from src/data.
