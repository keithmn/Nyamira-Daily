How to use:
  1. Click a Search or Place ID link — Google Maps opens
  2. Find the correct pin. Right-click it → "What's here?" — coordinates appear at the bottom
  3. Copy the coordinates (e.g. -0.5577, 34.929) and paste them into the input box
  4. When done, click Export JSON to save your work

Your entries are saved in your browser as you type. The exported JSON can be applied with npm run geo:apply.
