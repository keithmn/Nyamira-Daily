# Nyamira county budget: source data

The checked CSVs behind `data/county/nyamira/`. What each file is, how it was made and how to rebuild the figures: [`docs/county-budget/DATA.md`](../../../docs/county-budget/DATA.md).

| Folder or file | What |
|---|---|
| `pbb-2025-26/` | Programme Based Budget 2025/26: `departments.csv` (24 votes), `programmes.csv` (96 rows, names typed), `table9-reading.csv` (the machine reading of Table 9) |
| `bir-2025-26-q4/` | Fourth-quarter Budget Implementation Report FY2025/26, Table 4 |
| `cob-history/` | Controller of Budget figures FY2013/14 to FY2024/25, `checked.json` (where each was found) and `page-offsets.json` |
| `known-issues.csv` | Printed errors and how each is handled |
| `person-checks.csv` | What waits for a person |
| `pdfs/`, `text/` | Stored documents and their text, not in Git |
